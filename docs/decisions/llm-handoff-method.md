# LLM Handoff Method

## Decisions

- ChatGPT·Claude로 콘텐츠를 넘길 때는 변환 결과(선택된 프롬프트가 있으면 프롬프트+본문)를 클립보드에 복사한 뒤, 해당 서비스의 새 대화 페이지를 새 탭으로 여는 방식만 사용한다.
- URL 쿼리 파라미터로 상대 서비스의 입력창을 미리 채우는 "프리필" 방식은 사용하지 않는다.

## Boundaries

- 이 결정은 "본문(+프롬프트)을 외부 LLM 웹 채팅으로 넘기는" 모든 내보내기 동작에 적용된다. 지금은 ChatGPT·Claude 두 곳이지만, 이후 다른 LLM 서비스를 추가할 때도 같은 방식을 기본값으로 삼는다.
- 사용자가 새 탭에서 붙여넣기를 직접 한 번 실행해야 하는 것은 이 결정이 받아들인 트레이드오프이지, 결함이 아니다.

## Why

- ChatGPT(`chatgpt.com/?q=`)의 프롬프트 프리필은 OpenAI가 공식 문서화하지 않은, 커뮤니티가 발견한 동작이다. 길이 제한과 WAF 차단 위험이 있어 예고 없이 막히거나 바뀔 수 있다.
- Claude 웹(`claude.ai/new?q=`)의 동일한 프리필 파라미터는 2025년 10월경 제거되어 더 이상 동작하지 않는다. 현재 공식적으로 프리필을 지원하는 것은 Claude **데스크톱 앱** 전용 `claude://claude.ai/new?q=` 스킴(약 14,000자 제한)뿐이며, 데스크톱 앱이 없는 웹 사용자에게는 실패한다.
- 두 서비스를 클립보드 복사 방식으로 통일하면 서비스 쪽 정책 변경에 영향받지 않고, 콘텐츠 길이 제한도 없으며, 두 버튼의 체감 동작이 동일해진다.

## Reconsider when

- OpenAI 또는 Anthropic이 웹 채팅의 새 대화 프리필을 공식 API/쿼리 파라미터로 문서화해 발표하는 경우.
- 실제 사용 데이터에서 "붙여넣기 한 단계"가 충분히 불편하다는 신호가 쌓이는 경우.

## Still-rejected alternatives

- ChatGPT `?q=` URL 프리필 — 비공식·비문서화 동작이라 예고 없이 막히거나 바뀔 수 있고 긴 본문에서 실패함; OpenAI가 공식 지원을 발표하면 재검토.
- Claude 데스크톱 `claude://` 스킴 프리필 — 데스크톱 앱 설치 여부에 동작이 갈려 웹 전용 사용자에게 실패함; 이 서비스가 데스크톱 앱 설치를 전제할 수 있게 되면 재검토.

## Evidence worth preserving

- 2026-08-17 리서치: ChatGPT `?q=` 프리필은 OpenAI 개발자 커뮤니티 포럼에서만 언급되는 비공식 동작이며 공식 문서를 찾을 수 없었다. Claude 지원 문서("Open Claude Desktop with a link", support.claude.com)는 `claude://` 스킴이 데스크톱 앱 전용이며 웹(claude.ai)에서는 지원하지 않는다고 명시한다. `claude.ai/new?q=` 웹 파라미터는 검색 결과상 2025년 10월경 제거된 것으로 확인된다.
