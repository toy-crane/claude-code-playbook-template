# 팀 대시보드

배포 현황과 서비스 지표를 한 화면에서 보는 한국어 웹앱이다.
디자인 시스템은 `tokens.css` 하나로 관리하고 라이트와 다크를 모두 지원한다.
제품에는 이미 대시보드와 설정 화면이 있고, 알림 센터는 아직 없다.

알림은 배포 실패, 지연 경보, 팀원 멘션 세 종류다. 목록에서 알림을 열면
상세에서 원인과 관련 배포를 보고 담당자를 지정할 수 있다. 설정에서는
종류별로 이메일과 사내 메신저 수신을 각각 켜고 끌 수 있다.

샘플 알림은 「api-gateway 배포 실패 (2회 연속)」, 발생 시각은 어제 14:07,
담당자는 아직 없다.
