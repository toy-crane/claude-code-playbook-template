# 읽을거리

읽을 글을 저장해 두고 다시 여는 한국어 모바일 웹앱이다.
아직 제품 코드, 디자인 시스템, prototype.html은 없다.

전체 제품에는 보관함, 글 상세, 설정 화면이 필요하다. 보관함에서 글을
열고 상세에서 저장하거나 저장을 취소할 수 있다. 변경은 보관함에도
반영된다. 설정에서는 주간 다이제스트 수신을 켜고 끌 수 있다.

샘플 글은 「좋은 질문을 만드는 방법」, 저자는 김민서, 읽는 시간은 6분이다.
내용은 회의 전에 목적과 이미 아는 사실을 적어 두면 질문이 구체적으로
바뀐다는 이야기다. 첫 방문에는 아직 저장하지 않은 상태다.

현재는 글을 저장한 직후의 피드백 표현만 결정하고 있다.
전체 화면 검토와 제품 승인은 아직 진행하지 않았다.
