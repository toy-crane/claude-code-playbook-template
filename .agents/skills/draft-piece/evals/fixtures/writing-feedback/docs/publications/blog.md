# 작업 기록 블로그
## Readers and situations
개인 개발자가 작업 중 참고한다.
## Promised change
도구를 직접 확인하고 다음 행동을 판단할 수 있다.
## Voice
사실을 담백한 해요체로 설명한다. 공통 문체는 [글쓰기 기준](../decisions/writing.md)을 따른다.
## Coverage
직접 해 본 작은 기술 실험. 마케팅은 제외한다.
## Conventions
짧은 H2 절. content/posts/<slug>.md. 로컬 서버 없음; Markdown 파일로 본다.
## Evidence of a finished piece
본문만 읽고 독자 질문에 답할 수 있는지 확인한다. 실행할 코드가 있으면 실제로 실행한다.
